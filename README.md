# Excel Formula & Data Analysis Project

A practical Microsoft Excel project focused on applying essential and advanced spreadsheet formulas to student, sales, and employee datasets. The workbook demonstrates how Excel can automate calculations, classify records, retrieve information, and analyze data efficiently.


## Project Overview

The goal of this project is to practise Excel formulas and data-handling techniques using three worksheets. Each worksheet contains sample data and formula-based tasks designed to build practical spreadsheet skills.

## Workbook Structure

### 1. Project Instructions

Contains the project brief, essential tasks, and a checklist of the formulas and Excel features to practise.

### 2. Students Grade

Works with student records and marks. Typical tasks include:

- Calculating total and average marks.
- Assigning grades with nested `IF` formulas.
- Determining Pass/Fail results.
- Counting students who meet score conditions.
- Extracting high-performing students with `FILTER`.
- Working with dates and text functions.

### 3. Sales Data

Uses sales records to practise business calculations and analysis, including:

- Applying discount rules with `IF` and nested `IF`.
- Checking eligibility using `IF`, `AND`, and `OR`.
- Summarising records with `COUNTIFS`, `SUMIFS`, and `AVERAGEIFS`.
- Looking up product and salesperson information.
- Using `ROUND`, `CEILING`, and `FLOOR` for numeric calculations.
- Working with dates and dynamic ranges.

### 4. Employee Data

Focuses on employee information and formula-driven calculations, including:

- Calculating bonuses and salary plus bonus.
- Looking up employee details with `VLOOKUP` and `XLOOKUP`.
- Retrieving values dynamically with `INDEX` and `MATCH`.
- Calculating date differences and working with joining dates.
- Using relative and absolute cell references.

## Key Excel Skills

The project covers the following Excel concepts:

- Relative and absolute references (for example, `A1` and `$A$1`).
- Cell formatting and data input.
- `IF`, nested `IF`, `AND`, and `OR`.
- `COUNTIFS`, `SUMIFS`, and `AVERAGEIFS`.
- `VLOOKUP` and `XLOOKUP`.
- `INDEX` and `MATCH`, plus `XMATCH`.
- Text functions such as `LEFT`, `FIND`, `UPPER`, and `LOWER`.
- `INDIRECT` and `OFFSET` for dynamic references.
- Date and time calculations.
- `ROUND`, `CEILING`, and `FLOOR`.
- `FILTER` for returning records that meet conditions.

> **Note:** Some functions, such as `XLOOKUP`, `XMATCH`, and `FILTER`, require a compatible version of Microsoft Excel or another spreadsheet application that supports them.

## How to Use

1. Download or clone this repository.
2. Open the Excel workbook (`excel project 1.xlsx`) in Microsoft Excel or a compatible spreadsheet application.
3. Review the **Project Instructions** sheet first.
4. Open each worksheet and check the input data and formula columns.
5. Enter or adjust formulas where required by the task instructions.
6. Verify that results update correctly when source data changes.
7. Capture screenshots of the completed worksheets and place them in the `screenshots` folder.
